# lens-note · 镜头笔记

[English](README.md) | [简体中文](README.zh-CN.md)

**lens-note（镜头笔记）** 是一款 **100% 本地离线、零第三方依赖**的摄影数据复盘工具（基于 Python 3 纯标准库 + ExifTool）。只需指向一个或多个照片目录（例如同时汇总 `2025` 和 `2026`），即可生成**单个可离线打开的精美 HTML 复盘报告**，看清你的**焦段分布、出片率（打星率）、镜头性价比四象限、拍摄节奏与黄金拍摄时段**。

## 核心特点

- **聚焦“出片率（Keeper Rate）”**：不止统计快门数，更结合星标分析哪台机身、哪支镜头、哪个焦段、哪次拍摄真正帮你出片，帮你决定“哪支镜头该出、下一支该买什么”。
- **三层精准连拍归组（一键开关）**：优先读取相机硬件连拍标记（`ReleaseMode`/`ContinuousDrive`）、连拍序号（`SequenceNumber`）、`BurstUUID` 与包围曝光，无硬件标记时采用毫秒级（`≤0.65s`）或同秒兜底，绝不误伤正常连续单拍；归组后继承组内最高星标/旗标，也可一键切换回原始快门数。
- **RAW + JPG 智能去重**：同一目录下的 `DSC00001.JPG` + `DSC00001.ARW` + `DSC00001.xmp` 自动合并为 **1 张逻辑照片**，绝不因为近期未删 RAW 或打星保留 RAW 而重复计数。
- **全源星标融合（只读零改动）**：自动汇总图片内嵌星标、`.xmp` 边车，以及 **Lightroom Classic**（`.lrcat`）、**Capture One**、**像素蛋糕**、**影像之匠**、**Luminar Neo** 本地库中的星级与留用旗标。
- **多目录汇总 + 干扰隔离**：支持同时添加多个年份文件夹，只扫白名单目录并自动跳过 `Lightroom`、`backups`、`CLIP` 等无关文件夹与视频文件。
- **5 类器材自适应 + 7 档行业标准焦段**：支持**相机 / 无人机 / 云台相机（如 Pocket 3）/ 运动相机 / 手机**（无数据自动隐藏），采用行业标准的 7 档等效视角分桶（`≤20` / `21-30` / `31-44` / `45-64` / `65-115` / `116-250` / `>250`）消化半幅换算偏差；点击任意变焦镜头即可透视内部焦段热力图。
- **单文件离线 HTML + 双主题 + PNG 卡片导出**：零外链、零 CDN，支持 **暗房暗黑 ↔ 浅色画报**、**简体中文 ↔ English** 一键切换，支持点击日历格子钻取当日拍摄，以及 **一键导出高清分享长图 PNG**。
- **并发扫描 + 增量缓存**：多进程并发调用 ExifTool 加速首扫，后续按 `(路径, 修改时间, 大小)` 增量更新仅需数秒；对照片目录绝对只读，零污染。

## 快速上手

1. 确保系统已安装 **Python 3.9+**（无需安装任何第三方库）。
2. 双击 **`Start-LensNote.bat`** 按菜单添加 `2025` / `2026` 等照片文件夹即可生成；或者直接**选中一个或多个照片文件夹拖到 `Start-LensNote.bat` 图标上**。
   - 若未安装 ExifTool，启动时会提示一键自动下载官方 64 位版本到 `tools\`。
3. 生成的 HTML 报告保存在 `output\` 目录并自动在浏览器打开。

## 命令行用法

```bash
# 跨年份多目录合并复盘
python lens_note.py "D:\Windows\文档\2025" "D:\Windows\文档\2026"

# 跳过修图软件数据库，仅读图片内嵌与 .xmp 星标
python lens_note.py "D:\Windows\文档\2026" --no-db

# 忽略缓存强制全量重扫
python lens_note.py "D:\Windows\文档\2026" --no-cache

# 运行隔离自动化测试
python -m unittest discover -s tests -v
```
